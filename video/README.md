# Vídeos con Remotion

Proyecto independiente de la app Next.js. Genera un vídeo vertical (1080×1920, 6 s) anunciando el próximo partido.

1. `npm install`
2. `npm run studio` → abre el editor en el navegador para cambiar los datos y ver la animación.
3. `npm run render` → crea `out/partido.mp4`.
4. `npm run still` → crea `out/portada.png`.

Los datos del partido están en `src/Root.tsx`.
