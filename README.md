# Suite de Baloncesto

App de baloncesto: scouting, análisis de jugadores/rivales y herramientas para entrenadores.

Construida con [Next.js](https://nextjs.org) (App Router, TypeScript, Tailwind CSS) y lista para desplegar en [Vercel](https://vercel.com).

## Desarrollo local

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Despliegue en Vercel

El proyecto no necesita configuración adicional: Vercel detecta Next.js automáticamente.

1. Importa este repositorio en [vercel.com/new](https://vercel.com/new).
2. Vercel usará por defecto `npm run build` y servirá el directorio `.next`.
3. Cada push a `main` genera un despliegue de producción; cada rama/PR genera un preview.
